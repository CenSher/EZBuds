# 界面行为修正版：待用户验收

此版本完成代码、阴影资产、策略检查和编译，不使用 Computer Use、不自动操作耳机。当前状态是“待界面验收”，不是已通过视觉稳定性验收。

先从托盘退出旧版，再使用根目录“启动耳机控制中心.cmd”或本次发布目录的 exe。不要通过旧的预览快捷方式启动；新入口不带调试参数。

1. **冷启动 / 重复启动**：退出后重新打开，应仅显示托盘图标，不弹出菜单。再启动一次不展开已有菜单。
2. **自动收回**：托盘打开菜单后点击其他应用或桌面，应收回。连续开合十次，并分别在设备切换页、右键菜单关闭后、确认气泡取消后测试。再次显示已有面板后也必须能收回。
3. **完整阴影**：浅色 / 深色主题下，分别在白色空白窗口、文字密集窗口、桌面上打开菜单。四边应连续柔和，形状不跟随后面文字、电量条或设备列表变化。阴影中央不能使亚克力变成实色背景。
4. **缩放 / 恢复**：如条件允许，在 100%、125%、150%、200% 下检查阴影边缘，切换显示器和睡眠唤醒后重复开合。高对比度时不显示阴影是预期行为。
5. **标题点击**：点击设备名称任意文字或箭头，都应进入设备切换页；悬浮两处均显示“设备名称(点击以切换)”。箭头紧跟名称末尾，没有单独的悬浮方框。键盘 Tab 聚焦时仍保留焦点指示。

如仍有异常，请说明实际启动入口、启动后是否重启过旧进程、主题、缩放比例和触发步骤。可附该发布目录的 `BUILD_INFO.json` 与 `startup-error.log`；不要将仅编译通过作为验收结果。
