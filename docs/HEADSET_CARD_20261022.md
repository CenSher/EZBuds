# 耳机卡片合并与删除配置

发布目录：`releases/headset-card-20261022/`。根目录“启动耳机控制中心.cmd”更新到此版本；请先从托盘退出旧版再启动。没有自动启动程序或操作真实耳机。

## 设置页

- 移除上方独立的“已配置的耳机”卡片列表；保留下方大卡片的耳机图标、名称、连接状态、地址和型号说明。
- 大卡片右侧使用原生展开箭头，默认收起。展开后显示已配置耳机列表、添加入口以及每副耳机的切换、修改、删除按钮。
- 删除只移除本软件的型号绑定与保存名称，保留 Windows 蓝牙配对。删除非当前耳机不影响当前数据；删除当前耳机会清空旧电量和控制对象，等待明确选择另一副耳机，不自动切换到其他物理设备。
- 被删除的地址不会在下次自动识别时重新加入；仍可通过“添加耳机”手动恢复。删除保存失败会保留原绑定和当前选择。

## 验证

- 使用独立源码快照编译，保留同时进行的文案悬浮提示修改。源码 SHA256 和构建状态在发布目录 `BUILD_INFO.json` 中。
- 263 项模拟蓝牙/配置回归检查通过，其中新增 13 项删除与重新选择检查；不发送真实设备命令。
- 24 项窗口策略检查、现有界面源代码约定和阴影资产检查通过。
- 界面布局、原生展开动画和真实耳机切换仍待用户手动验收。

## 手动验收

1. 设置 → 蓝牙和设备：顶部只保留一张大耳机卡片。点击右侧箭头，检查展开与收起。
2. 展开后添加另一副耳机，点击切换，检查卡片和电量是否随所选耳机更新。
3. 删除非当前耳机：当前耳机信息应保留，Windows 配对不受影响；重启后不应自动加回。
4. 删除当前耳机：旧电量与操作状态应清空；即使列表还有其他耳机，也应等待手动切换。
5. 删除最后一副耳机：显示添加提示；通过添加入口可恢复仍在 Windows 中配对的耳机。
