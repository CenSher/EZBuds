# 设置窗口尺寸与最大化布局：待用户界面验收

发布目录：`releases/settings-window-20261022/`。根目录“启动耳机控制中心.cmd”已更新，请先从托盘退出旧版再启动。

## 修改

- 最小窗口尺寸以 800 × 600 为逻辑基准，按当前窗口所在显示器的 DPI 换算为物理像素。使用原生 `OverlappedPresenter.PreferredMinimumWidth/Height` 限制拖动缩小；不在尺寸变化事件中反复强制调整窗口。
- 移动到其他显示器或缩放变化后重新计算限制；工作区小于基准尺寸时，以可用工作区为上限，避免窗口最低高度超过屏幕。
- 滚动容器明确横向拉伸；新增有限宽度的内容容器，内容宽度绑定其实际宽度并保留 1040 DIP 最大阅读宽度。内容始终从导航栏右侧的统一左边距开始排列，避免最大化后右移或右侧卡片、按钮被裁掉。
- 保留正常最大化功能，不设置最大窗口尺寸；此前开关、折叠菜单、耳机配置和托盘逻辑保留。

## 验证

通过 Microsoft Learn MCP 查阅[窗口管理官方文档](https://learn.microsoft.com/windows/apps/develop/ui/manage-app-windows)，采用稳定的 OverlappedPresenter 最小尺寸接口；未引入仍标为实验性的 Window.MinWidth/MinHeight。

独立源码快照完整构建通过；源代码布局约束检查、界面约定、阴影资产和 24 项窗口策略检查通过。发布目录 `BUILD_INFO.json` 记录源码校验值，交付前与当前源码一致。本次未自动操作界面或耳机，也未重复运行与此布局变更无关的蓝牙回归。

请手动验收：将窗口缩到最小；最大化并在四个设置页面间切换，检查右侧按钮与卡片是否完整；恢复窗口大小；如有多显示器，再跨不同缩放比例的显示器拖动检查。
