# 开机自启动

## 启动时的默认耳机

- 启动后先读取 Windows 本地已配对设备及实时连接状态，唯一已连接的已适配耳机优先于上次保存的离线耳机。
- 多副已适配耳机同时连接时，上次目标若仍连接则保留；否则进入选择状态，不按名称或地址随意挑选。
- 没有耳机连接时保留已有选择；首次使用只有一个可识别型号时可预选该型号，但不会主动连接。
- 即使关闭托盘电量显示，也会完成此本地选择步骤；此步骤不打开 RFCOMM、不读取耳机数据、不连接或断开设备。
- 首次打开主面板和设置会等待这一步完成（最多等待 5 秒，失败可手动刷新），避免先展示上次的目标。正常启动仍不弹出窗口。
- 用户删除过的耳机不会被自动加回；主动删除当前绑定后产生的“等待手动选择”状态，以及显式诊断地址参数，仍被尊重。
- 启动后的菜单展开前还会按下述规则检查一次；后台刷新不会自行切换耳机。

## 展开菜单前选择已连接耳机

- 点击托盘展开菜单时，先等待正在进行的耳机操作完成，再检查 Windows 实时连接状态，必要时切换，最后才加载并显示菜单。已缓存的菜单也执行同一流程。
- 当前选中耳机已连接时保留它；当前耳机未连接时，选择另一副已配对、已适配且已连接的耳机。没有合适目标时保持原选择，照常打开菜单。
- 同时存在多副候选耳机时，按已保存配置的顺序优先选择；新识别且未配置的候选排在后面，并以地址固定顺序。不自动恢复用户删除的绑定，不覆盖明确要求手动选择的删除状态或诊断地址。
- 选择前再次确认候选仍连接。检查与切换只读本机蓝牙状态、保存本地选择，不主动连接、断开或发送耳机控制命令；电量和设备数据仍按原流程刷新。切换后先清空旧耳机电量、设备列表和降噪状态，避免显示串用数据。
- 此检查独立于托盘电量开关，最多等待 5 秒（含等待已有操作）。超时或失败后展示当前选择；取消后的读取不会延迟提交切换。检查期间再次点击托盘、打开设置或退出，会取消本次展开。
- 重复要求显示已展开菜单时只激活窗口。“连接到耳机”是针对当前目标的明确命令，不触发自动改选。
- 本轮仅编译和源码检查；未执行自动界面或耳机测试，实际体验待用户验收。

入口：设置 → 个性化 → 启动。默认关闭，不会在普通启动或构建时写入自启动配置。

启用后注册当前用户的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\FreeClipControl`，内容为带双引号的当前 EXE 完整路径及 `--background`。关闭仅删除此应用的注册值。每次修改后读取验证，失败显示错误；设置窗口激活时刷新注册状态。不会修改 Windows 的 StartupApproved 状态，也不会绕过系统禁用。

便携版请保留整个发布目录。移动或升级到另一个目录后，在新程序设置中重新注册当前位置。删除前先关闭自启动；若已经删除，可在注册表中移除此应用的上述值。应用不在普通启动时自动抢占另一份便携版的注册路径。

## 手动验收（待用户执行）

- 从根目录入口启动新版；设置中开启，再关闭并重新打开设置，确认状态保存。
- 开启后注销并重新登录 Windows，确认仅出现一个托盘图标，不弹出面板；重复启动仍不展开面板。
- 关闭后再次登录，确认不再自动启动。
- 在 Windows 启动设置禁用后确认系统禁用有效，再在系统中恢复。
- 将整个目录复制到新位置并运行，在设置中更新自启动位置，确认下一次登录启动新位置。
- 按 UI_CONTRACT.md 验收菜单自动收回、页面切换、浅深主题和 DPI 阴影。

编译和代码检查不能替代登录、界面或耳机实机验收。
