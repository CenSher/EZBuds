# 参考 Windows 设置的自适应版式：待用户界面验收

发布目录：`releases/settings-responsive-20261022/`。根目录“启动耳机控制中心.cmd”指向此版本，请从托盘退出旧版后再启动。

## 版式

- 所有页面共享相对侧栏右侧居中的内容容器，最大宽度 1000 DIP。页标题与卡片左边缘统一对齐；导航栏使用 NavigationView 原生展开宽度。
- 使用内容视口实际宽度设置页面宽度，窗口缩放、最大化、恢复以及导航栏展开/收起均走同一套规则。可用内容宽度达到 880 DIP 时分为两列，列间距 12 DIP；不足时回到单列。
- 蓝牙和设备：当前耳机摘要横跨顶部；宽屏下耳机电量在左、连接操作在右，窄屏按原顺序纵向排列。
- 耳机配置：宽屏下设备/型号选择与型号库并排，窄屏下上下排列。
- 个性化：宽屏下主题和主菜单文案位于左列，系统托盘位于右列；窄屏下按主题、文案、托盘顺序纵向排列。关于页沿用共享居中容器。
- 800 × 600 最小尺寸、原生折叠交互、导航动画、开关与耳机管理功能保留。

布局依据本次用户参考图及通过 Microsoft Learn MCP 查阅的[自适应布局文档](https://learn.microsoft.com/windows/apps/develop/ui/layouts-with-xaml)。没有引入参考图中的账号、系统搜索等额外功能。

## 检查与验收

独立源码快照完整构建通过。界面源代码约定、阴影资产和 24 项窗口策略检查通过；静态检查确认三个自适应页面均具有两列容器。发布目录 `BUILD_INFO.json` 记录源码 SHA256，交付前与当前源码一致。

本次只调整界面容器、宽度与位置，未改变耳机协议或配置逻辑，未自动打开界面或操作耳机。编译与源代码检查不代表实际视觉验收。

请在最大化及普通窗口下分别查看四页，拖动窗口宽度经过单双列切换位置，检查标题、卡片和右侧按钮是否完整；并检查展开耳机列表、展开抽象文案后布局是否自然。如有不同缩放的显示器，可再跨屏检查。
