# 设备配置版手动验收

本轮不使用 Computer Use、不自动操作界面或耳机。代码隔离检查使用模拟蓝牙和模拟上游响应；界面和实机结果由用户验证。

先从托盘退出正在运行的旧程序，再打开 `releases/device-config-20261022/FreeClipControl.Shell.exe`。两个版本共用单实例锁，旧版不退出时，新启动会直接退出。

1. **自动收回**：打开托盘面板，点击桌面或其他应用，面板应自动滑回。重复打开 / 收起、切换窗口、按 Esc、右键菜单关闭后均应正常。`--preview` 现在只控制预览启动；只有显式 `--keep-open` 才关闭自动收回。
2. **配置默认值**：设置左侧应出现“耳机配置”。选择名称包含 FreeClip 2 等已知关键词的蓝牙设备，应自动选中对应型号；未知名称且未保存过绑定时型号为空，手动选择后保存。
3. **已绑定列表**：在“蓝牙和设备”应看到保存过的设备卡片，显示设备名、型号、状态与当前设备。展开可查看地址、切换或修改配置。离线设备保留卡片，不伪装成在线。
4. **菜单切换**：点击耳机名称旁的右箭头，主内容应向左进入设备切换列表。点击已配置设备后返回其菜单；返回按钮向相反方向滑动。选择离线设备时应显示未连接，不显示上一副耳机的电量。
5. **导入**：导入发布目录 `Examples/headset-profile.example.json`，应出现自定义示例型号；无效 JSON、越界通道、尝试覆盖内置 ID 等应提示失败并保留原型号库。
6. **上游更新**：点击从 OpenFreebuds 更新，应显示更新进度，成功后刷新列表与更新时间。断网时失败提示应明确，原型号和设备绑定不丢失。
7. **保存和重启**：退出重开后，当前设备及全部绑定仍存在。已绑定耳机改名后仍按地址识别其型号。
8. **首次匹配**：没有保存绑定的新用户环境启动时，已配对且名称能匹配的设备自动建立绑定，不自动弹设置；若无法匹配，菜单显示“未能匹配耳机”和“打开软件设置”，点击进入耳机配置。蓝牙关闭、没有适配器和已匹配但未连接仍分别显示原有提示。

本版没有新增实物型号验证，也未重新验证播放中的连接锁定稳定性。遇到问题请记录型号、操作步骤、显示结果和实际音频行为。
