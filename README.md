# EZBuds

**在 Windows 上控制华为 / 荣耀蓝牙耳机的开源托盘工具。**

不依赖厂商官方 PC 应用，不需要管理员权限：通过耳机侧的 SPP 控制通道（RFCOMM）直接读取电量、切换降噪、管理耳机侧的已连接设备。控制协议来自真机抓包研究（见 [PROTOCOL.md](PROTOCOL.md)），只使用已配对设备的普通用户权限。

## 功能

- **托盘面板**：原生亚克力材质的无标题栏面板，从任务栏边缘滑入滑出；默认仅驻留托盘，点击托盘图标展开，失焦自动收回。
- **电量显示**：左耳 / 右耳 / 充电盒分项电量与充电状态（支持分项电量的型号），托盘悬浮提示取左右耳较低值。
- **噪声控制**：降噪 / 关闭 / 透传切换，降噪模式下可调强度；每次切换以耳机回读确认为准（[噪声控制说明](docs/NOISE_CONTROL.md)）。
- **设备管理**：读取耳机侧的已配对设备表（而非 Windows 配对列表），连接 / 断开任意设备；"连接到耳机"可在容量未满时把音频请求回这台电脑。
- **本次连接锁定**：将耳机锁定到本机，防止其他已连接设备抢占音频（[连接锁定说明](docs/CONNECTION_LOCK.md)）。
- **多型号支持**：内置 21 个华为 / 荣耀型号配置，可导入自定义 JSON 或从 OpenFreebuds 更新（[型号支持](docs/MODEL_SUPPORT.md)、[自定义配置](docs/CUSTOM_PROFILES.md)）。
- **其他**：系统 / 浅色 / 深色主题遵循、开机自启动（用户注册，无需管理员）、内存生命周期管理（[说明](docs/MEMORY_LIFECYCLE.md)）。

## 系统要求

- Windows 10 19041 或更高版本，x64。
- 耳机已在 Windows 蓝牙设置中完成配对。
- 运行时不要与其他占用 SPP 控制通道的程序（如 OpenFreebuds、协议探针）同时使用。

## 构建与运行

需要 .NET 8 x64 SDK，在仓库根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\build-shell.ps1
```

- 构建前会自动运行界面约定、阴影资产与窗口策略检查；依赖已还原时可加 `-NoRestore`。
- 输出为 `dist-current/EZBuds.exe`（自包含目录，分发时保留整个文件夹）；本地开发可用根目录 `启动EZBuds.cmd` 启动。
- 默认启动仅驻留系统托盘，点击托盘图标展开面板；重复启动同一程序不会强行弹出已有实例。
