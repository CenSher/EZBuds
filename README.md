# EZBuds

软件正式名称为 **EZBuds**。最新入口为根目录 `启动EZBuds.cmd`，本次发布到 `releases/delete-confirm-20261025/EZBuds.exe`；旧的 `启动耳机控制中心.cmd` 作为兼容入口指向同一版本。关于页显示名称、版本、作者（By Karthy）、GitHub 项目链接及 OpenFreebuds（GPL-3.0）致谢。默认启动只驻留托盘；请先退出旧进程。此次只编译和检查源码约定，未启动软件或运行测试。

当前版本为设备配置版：在设置 → 耳机配置中选择蓝牙设备和型号，自动推荐关键词匹配到的型号，并按地址保存。蓝牙和设备页通过当前耳机大卡片展开管理已配置列表；主菜单名称旁的箭头进入设备切换列表。内置 21 个型号配置，可导入自定义 JSON 或从 OpenFreebuds 更新。说明见 [型号支持](docs/MODEL_SUPPORT.md)、[自定义配置](docs/CUSTOM_PROFILES.md)和[手动验收](docs/DEVICE_CONFIG_ACCEPTANCE.md)。

原 FreeClip 2 基板已固定保存于 [baselines/FreeClip2-20261022-154252](baselines/FreeClip2-20261022-154252/)，包含源码、完整可运行目录和 SHA256 校验清单。早期 WPF 原型、上一代 WinUI 和旧界面试验构建已清理，协议探针、抓包助手和故障记录保留。

当前默认版本为重新实现窗口与动画的 **EZBuds**，使用 C# / .NET 8、WinUI 3 和 Windows App SDK 2.5.1。源码与详细说明见 [FreeClipControl.Shell/README.md](FreeClipControl.Shell/README.md)。

- 原生亚克力磨砂材质、轻阴影、无标题栏的托盘面板。
- 默认启动仅显示托盘图标，主动点击后才展开面板；重复启动不强制弹出已有面板。
- 每次启动优先选择当前唯一已连接的已适配耳机，关闭后台电量显示时也生效。多副同时连接时保留仍连接的上次目标，否则等待手动选择；运行中仍尊重手动选择。
- 电量区下方提供噪声控制下拉框：降噪 / 关闭 / 透传。降噪模式下，已适配型号额外显示降噪强度下拉框。仅在当前型号已适配且设备返回有效模式后显示，结果以耳机回读为准，见 [噪声控制说明](docs/NOISE_CONTROL.md)。
- 菜单按需创建，首次布局和阴影加载完成后才展开；收起后缓存 7 分钟再回收。设置关闭时解除绑定、取消界面等待并释放窗口内容。后台托盘仅查询电量，独立于菜单存在。内存机制及待手动验收项目见 [内存生命周期](docs/MEMORY_LIFECYCLE.md)。
- 设置 → 个性化 → 启动可开启“开机自启动”，默认不注册。开启后以当前用户身份登录 Windows 时仅驻留托盘，无需管理员权限。开关反映应用自启动注册状态；Windows 系统中禁用启动项时，请通过旁边的“Windows 启动设置”恢复。移动或更新便携版目录后，在新版本设置中点击“将自启动更新为当前位置”（或关闭再开启）；删除软件前先关闭自启动。
- 系统合成的整块面板从任务栏边缘外滑入，收起时滑回边缘外，不改变透明度；收起和真正退出均等待动画完成，不逐帧移动窗口。
- 类似 Windows WLAN 的设备列表：默认收起操作，单选后显示蓝色选中条与连接 / 断开按钮。
- 已连接设备优先，未连接设备置灰；参考图绘制电脑、手机、平板、左右耳与充电盒矢量图标，支持右键指定未知设备类型。主面板不滚动、不显示更新时间，托盘右键弹出独立菜单。
- 支持系统 / 浅色 / 深色主题，遵循系统关闭动画与高对比度设置。
- 托盘菜单提供连接到耳机、设置及退出；设置使用 Windows 风格的独立窗口，主题选择在设置中保存。
- 托盘悬浮显示当前型号及电量；分项型号取左右耳较低值，整体电量型号显示整体值。已有 FreeClip 2 的条件音频请求逻辑保留。
- 设置 → 个性化中的开关靠右显示；抽象文案默认折叠，保留原生展开/收起动画。设置各页切换时上滑进入，遵循系统动画开关。
- 可关闭“悬浮查看耳机电量”：托盘仅显示耳机名，停止后台启动读取和定时刷新；主动打开耳机面板或“蓝牙和设备”页时仍正常读取。设置会保存，旧配置默认开启。
- 通过真实 RFCOMM/SPP 接口读取 FreeClip 2 的分项电量、充电状态和耳机侧设备表，用户点击后发送连接 / 断开命令并读取结果确认。
- FreeClip 2 的设备卡片仅对已锁定设备追加“已锁定”，展开后可确认锁定或解锁对应设备；按设备地址发送单次指令并回读核对。跨设备扩展已编译，未做实机验收；见 [连接锁定说明](docs/CONNECTION_LOCK.md)。

```powershell
powershell -ExecutionPolicy Bypass -File .\build-shell.ps1 -Run
```

常规构建输出为 `dist-current/EZBuds.exe`，并更新根目录启动入口。构建前自动运行 UI 约定、阴影资产与启动/收回策略检查，构建期间源码变化会报错阻止交付。分发时保留整个输出目录。首次还原需要访问 NuGet；依赖已还原时可传 `-NoRestore`。

新版采用原生弹窗样式，分别实现窗口生命周期、圆角材质、合成动画与设备面板。默认 `build.ps1` 构建多型号版；旧版入口已移除。

默认版本已接入真实蓝牙数据，不再使用演示数据。此次只完成编译，真机读取和切换由用户手动验收，尚未声称新客户端已验证成功。先在系统中配对耳机，并关闭占用 SPP 通道的其他控制程序；使用方式和断开本机后的行为见 [蓝牙接入说明](FreeClipControl.Shell/README.md)。

协议研究及探针见 `PROTOCOL.md`、`probe/`、`HANDOFF.md`。`HANDOFF.md` 保留最初的协议研究与开发背景；其中的技术选型和开发顺序不代表当前实现。

清理清单和释放空间记录见 `docs/LEGACY_CLEANUP.json`。旧版本构建与当前构建不要同时运行，以免争用耳机控制通道。
